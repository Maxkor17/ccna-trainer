# CCNA тренажер

Веб-додаток для підготовки до Cisco CCNA: ITN 1–17, SRWE 1–16, ENSA 1–14: питання з розбором кожного варіанту, генератори розрахунків (субнетинг, VLSM, IPv6, STP), CLI-лаби з симулятором IOS (мережі з комутаторів, маршрутизаторів, ПК і серверів: VLAN, trunk, router-on-a-stick, STP, статичні маршрути, OSPF, DR/BDR, ACL, NAT/PAT, DHCP і relay; ping/tracert/curl/ssh з ПК), режим Troubleshooting із випадковими поломками, симуляція CCNA 200-301 за вагами доменів, план до дати екзамену, шпаргалки по всіх темах, питання зі схемами топології та «заповни пропуски», імпорт карток з Obsidian (.md) і експорт слабких місць назад у vault, пісочниця (власна мережа), анімований шлях пакета, HSRP/OSPF cost/NTP-Syslog-SNMP лаби, REST API лаба автоматизації, повний англійський переклад банку CCNA (режим «English» у налаштуваннях) і словник UA↔EN, карта покриття іспиту за обома blueprint (v1.1 до 02.02.2027 і v2.0 з 03.02.2027) з прогнозом здачі, симлети (кілька питань до виводів show), EtherChannel/STP/port-security/DHCP snooping/DAI/DHCPv6 у симуляторі й візуалізатор «STP покроково», «Сесія дня», причини помилок і власні пояснення, звіти про помилки в питаннях, Pomodoro, тижневий огляд і віхи до іспиту, швидкісні тренування (субнетинг, команди), аналіз «що я плутаю», календар активності й досягнення, облік часу навчання (автотаймер + ручні записи Packet Tracer/NetAcad/Obsidian) і норма за часом, щоденний чек-ін «що вивчив / план на завтра» з журналом, офлайн-режим і встановлення як застосунок, екзамен на час, повтор помилок з інтервальним повторенням, статистика й денна норма.

Також є: root/loop guard, storm control, RA guard, VRRP, OSPFv3, AAA з TACACS+/RADIUS, SCP/SFTP, GRE, QoS (MQC, LLQ, mls qos), DHCP option 43, DNS-сервер і `nslookup`/`dig`, розширений `ping`, `show logging`, фільтри `| include/section/begin/count` і Linux/macOS-команди на ПК. CLI-лаби є для кожного модуля SRWE і ENSA. Окрема лаба Ansible (ENSA14) виконує YAML-плейбуки з `ios_command`/`ios_config` на пристроях симулятора. Troubleshooting має режим тікетів: скарга користувача, таймер і оцінка. Додано симлети з аналізом захоплення пакетів, симуляцію CCNA англійською з часом на кожне питання, вкладки головної, інтервальне повторення лаб (7 → 21 → 60 днів) і адаптивну складність. Картки можна імпортувати прямо з GitHub-репозиторію vault. Помилки JavaScript записуються в розділ «На виправлення».

Додано пізніше:
- лаба «Невідома мережа» (CDP discovery);

### Дані у Firestore
`users/{uid}/progress/state` — прогрес питань, позначки (а також власні пояснення `my:*`, тижневі огляди `wk:*`, віхи `ms:*`), лаби;

`users/{uid}/errors/*` — помилки JavaScript з усіх ваших пристроїв (до 10 за сеанс). Старе поле `daily` у `progress/state`
переноситься автоматично при першому вході з новою версією; правила доступу (`firestore.rules`) міняти не потрібно.

## Налаштування (≈30 хв, один раз)

### 1. Firebase-проєкт
1. Відкрий <https://console.firebase.google.com> → **Create a project** (наприклад, `ccna-maksym`). Google Analytics можна вимкнути. План — **Spark (безкоштовний)**, картку не додавай.
2. **Build → Authentication → Get started → Sign-in method**: увімкни **Google** і **Email/Password**.
3. **Build → Firestore Database → Create database** → регіон `eur3 (europe-west)` → **Start in production mode**.
4. Вкладка **Rules** у Firestore → встав вміст файлу `firestore.rules` → **Publish**.
   *Порада:* щоб увійти міг лише ти, розкоментуй рядок з `request.auth.token.email` і впиши свій email.
5. **Project settings (⚙) → General → Your apps → `</>` (Web)** → назва `ccna-web` → **Register app** (Firebase Hosting НЕ потрібен). Скопіюй об'єкт `firebaseConfig`.
6. Встав значення у `public/firebase-config.js` замість `ВСТАВ…` і закоміть.

### 2. GitHub Pages
1. Репозиторій має бути **публічним** (безкоштовний GitHub Pages працює з публічними репозиторіями; прогрес усе одно приватний — він у Firestore під правилами доступу).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Зроби будь-який push у `main` (або **Actions → Deploy to GitHub Pages → Run workflow**). За 1–2 хв сайт буде на `https://<логін>.github.io/ccna-trainer/`.

### 3. Дозволити домен для входу
Firebase → **Authentication → Settings → Authorized domains → Add domain** → `<логін>.github.io`.

### 4. Перенести прогрес зі старої версії
У старому тренажері (артефакт Claude): **💾 Копія → Копіювати** → у новому: увійди → **💾 Копія → Імпорт** → встав → **Імпортувати**.

### 5. Встановити на телефон
- Android (Chrome): меню ⋮ → **Встановити додаток**.
- iPhone (Safari): **Поділитися → На екран «Додому»**.

## Як оновлювати питання
Банки питань — звичайні JS-файли в `public/`. Формати:

```js
// Один або кілька правильних варіантів (у тексті питання додай «Оберіть два.»)
{id:"унікальний-id", t:"SRWE3", q:"Питання?", c:"необов'язковий вивід show",
 o:[["Варіант A","Пояснення"],["Варіант B","Пояснення"]], a:[0], src:"na", n:"примітка"}
// Розставити по порядку (items — у правильному порядку)
{id:"…", t:"SRWE1", type:"order", q:"…", items:["крок 1","крок 2","крок 3"], e:"пояснення"}
// Зіставити
{id:"…", t:"SRWE5", type:"match", q:"…", pairs:[["ліве","праве"],…], e:"…"}
// Ввести команду (приймаються скорочення IOS)
{id:"…", t:"SRWE3", type:"cmd", q:"…", ans:["show interfaces trunk"], e:"…"}
```
`t` — тема (`ITN1`…`ITN17`, `SRWE1`…`SRWE16`, `ENSA1`…`ENSA14`), `src` — `"n"` (з нотаток) або `"na"` (NetAcad). `id` не змінюй після публікації — до нього прив'язаний прогрес.

Після push у `main` сайт оновиться автоматично.

### Як змінювати симулятор
Редагуйте фрагменти в `src/cli/`, потім `node scripts/build-cli.mjs` і закомітьте і фрагменти, і `public/cli.js`. CI перевіряє, що вони збігаються (`--check`). Фрагменти — частини одного IIFE, тому окремий фрагмент сам по собі не є валідним JS.

## Ліміти Firebase Spark
Firestore: 1 ГіБ даних, 50 000 читань і 20 000 записів на день. Тренажер робить один запис на відповідь — запас у сотні разів. Якщо ліміт колись буде вичерпано, додаток продовжить працювати локально, а синхронізація відновиться наступного дня.

## Резервні копії
Раз на тиждень тренажер сам робить знімок прогресу: 8 останніх — у Firestore (`users/{uid}/backups`), 4 останні — у браузері. Відновлення: **💾 Копія → Автоматичні копії → Відновити** (дані об'єднуються).

**💾 Копія → Завантажити файл** — ручний JSON з усім прогресом.

## Нагадування
**⚙ Налаштування → Нагадування → Додати в календар** завантажує щоденну подію `.ics`. Її підхоплює календар телефона, тож нагадування працює без сервера й без відкритого тренажера.
